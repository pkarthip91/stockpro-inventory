# Product List Import

The Products page includes an **Import Product List** action for the transcribed physical stock list.

- It creates missing products and updates matching products.
- Product creation does not ask for opening stock. Normal stock changes should use **Stock In** and **Stock Out**.
- Bulk quantity and bulk price are optional and have no default value in Add Product.
- Some handwritten names were marked for review in the source data because the writing is ambiguous.
